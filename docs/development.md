# Development

Ganana BFF の開発環境・開発フローのドキュメント。

## 技術スタック

| 項目 | 採用 |
| --- | --- |
| 言語 | Go |
| Web フレームワーク | Gin |
| 設定管理 | Viper |
| ロギング | `log/slog`（標準ライブラリ） |
| HTTP クライアント | 標準 `net/http` + `golang.org/x/sync/errgroup` |
| テスト | 標準 `testing` + testify |

詳細な技術選定理由は [architecture.md](./architecture.md) を参照。
